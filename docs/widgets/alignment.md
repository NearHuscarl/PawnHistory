# Alignment

Normalized child alignment value.

| Member | Default | Does |
| --- | --- | --- |
| `X` | ctor | Horizontal alignment from `-1` left to `1` right. |
| `Y` | ctor | Vertical alignment from `-1` top to `1` bottom. |
| `TopLeft/TopCenter/TopRight` | preset | Top alignments. |
| `CenterLeft/Center/CenterRight` | preset | Center alignments. |
| `BottomLeft/BottomCenter/BottomRight` | preset | Bottom alignments. |
| `AlongX(available, size)` | none | Converts `X` into a horizontal offset. |
| `AlongY(available, size)` | none | Converts `Y` into a vertical offset. |
