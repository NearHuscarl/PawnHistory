# BoxDecoration

Simple decoration data for `DecoratedBox`.

| Member | Default | Does |
| --- | --- | --- |
| `Color` | `null` | Optional solid background color. |
| `Border` | `false` | Draws a Verse border when `true`. |
| `PaintBackground(rect)` | none | Draws the background portion. |
| `PaintForeground(rect)` | none | Draws the foreground portion. |
