# Button

Text button.

| Member | Default | Does |
| --- | --- | --- |
| `label` | none | Button text. |
| `onClick` | none | Called on click. |
| `width` | `null` | Fixed width; when omitted, width is text width plus theme button padding. |
| `height` | `null` | Fixed height; when omitted, uses `ctx.Theme.ButtonHeight`. |
| `enabled` | `true` | Enables or disables the control. |
| `key` | `null` | Explicit identity for this button. |
