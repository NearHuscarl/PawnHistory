# Column

Vertical flex layout.

| Member | Default | Does |
| --- | --- | --- |
| `children` | none | Children laid out top to bottom. |
| `mainAxis` | `StackMainAxis.Start` | Vertical content alignment. |
| `crossAxis` | `StackCrossAxis.Center` | Horizontal child alignment. |
| `gap` | `ctx.Theme.Gap` | Child gap when omitted. |
| `key` | `null` | Explicit identity for this node. |
