# ConstrainedBox

Constraint override wrapper.

| Member | Default | Does |
| --- | --- | --- |
| `child` | none | Wrapped child. |
| `minWidth` | `null` | Minimum width within the parent constraint range. |
| `maxWidth` | `null` | Maximum width within the parent constraint range. |
| `minHeight` | `null` | Minimum height within the parent constraint range. |
| `maxHeight` | `null` | Maximum height within the parent constraint range. |
| `key` | `null` | Explicit identity for this wrapper. |
