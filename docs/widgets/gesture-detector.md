# GestureDetector

Mouse input wrapper around a child.

| Member | Default | Does |
| --- | --- | --- |
| `child` | none | Wrapped child. |
| `onTap` | `null` | Called on left mouse down over the rect. |
| `onSecondaryTap` | `null` | Called on right mouse down over the rect. |
| `onHover` | `null` | Called while the mouse is over the rect. |
| `enabled` | `true` | Enables or disables interaction. |
| `key` | `null` | Explicit identity for this wrapper. |
