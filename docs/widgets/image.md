# Image

Texture display widget.

| Member | Default | Does |
| --- | --- | --- |
| `texture` | none | Texture to draw. |
| `scaleMode` | `ScaleMode.ScaleToFit` | Unity texture scale mode. |
| `color` | `null` | Optional GUI tint while drawing. |
| `key` | `null` | Explicit identity for this image. |
