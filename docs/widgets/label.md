# Label

Text display widget.

| Member | Default | Does |
| --- | --- | --- |
| `text` | none | Label text. |
| `font` | `GameFont.Small` | Font used for measure and draw. |
| `anchor` | `TextAnchor.MiddleLeft` | Text alignment used for measure and draw. |
| `width` | `null` | Fixed width; when omitted, bounded labels use max width and unbounded labels use text width. |
| `height` | `null` | Fixed height; when omitted, height comes from text layout. |
| `color` | `null` | Optional GUI color override while drawing. |
| `key` | `null` | Explicit identity for this label. |
