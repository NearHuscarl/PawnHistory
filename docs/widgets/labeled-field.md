# LabeledField

Fixed-label form row.

| Member | Default | Does |
| --- | --- | --- |
| `label` | none | Left-side label text. |
| `field` | none | Right-side field widget. |
| `labelWidth` | none | Fixed label column width. |
| `gap` | `ctx.Theme.Gap` | Space between label and field when omitted. |
| `minHeight` | `ctx.Theme.TextFieldHeight` | Minimum row height when omitted. |
| `key` | `null` | Explicit identity for this row. |
