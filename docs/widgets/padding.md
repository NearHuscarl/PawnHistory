# Padding

Inset wrapper.

| Member | Default | Does |
| --- | --- | --- |
| `child` | none | Wrapped child. |
| `insets` | none | Per-edge padding. |
| `key` | `null` | Explicit identity for this wrapper. |
| `All(child, value)` | none | Applies the same padding to all sides. |
| `Left/Right/Top/Bottom(child, value)` | none | Applies padding to one side only. |
