# Positioned

Child rect resolver for `Stack`.

| Member | Default | Does |
| --- | --- | --- |
| `child` | none | Wrapped child. |
| `left` | `null` | Left offset from parent rect. |
| `top` | `null` | Top offset from parent rect. |
| `right` | `null` | Right offset from parent rect. |
| `bottom` | `null` | Bottom offset from parent rect. |
| `width` | `null` | Explicit child width. |
| `height` | `null` | Explicit child height. |
| `key` | `null` | Explicit identity for this wrapper. |
