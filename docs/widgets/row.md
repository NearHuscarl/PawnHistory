# Row

Horizontal flex layout.

| Member | Default | Does |
| --- | --- | --- |
| `children` | none | Children laid out left to right. |
| `mainAxis` | `StackMainAxis.Start` | Horizontal content alignment. |
| `crossAxis` | `StackCrossAxis.Center` | Vertical child alignment. |
| `gap` | `ctx.Theme.Gap` | Child gap when omitted. |
| `key` | `null` | Explicit identity for this node. |
