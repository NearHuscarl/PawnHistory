# ScrollView

Scrollable viewport around one child.

| Member | Default | Does |
| --- | --- | --- |
| `child` | none | Scrollable content. |
| `vertical` | `true` | `true` for vertical scrolling, `false` for horizontal. |
| `key` | `null` | Explicit identity for stored scroll position. |
| `controller` | `null` | Optional programmatic scroll controller. |
