# Theme

Shared spacing and sizing defaults.

| Member | Default | Does |
| --- | --- | --- |
| `ScrollbarSize` | `16f` | Reserved scrollbar width. |
| `ButtonHorizontalPadding` | `16f` | Horizontal padding used by `Button`. |
| `ButtonHeight` | `32f` | Default button height. |
| `TextFieldHeight` | `32f` | Default single-line text field height. |
| `PaddingXs` | `4f` | Small padding value. |
| `Padding` | `8f` | Normal padding value. |
| `GapXs` | `4f` | Small gap value. |
| `Gap` | `10f` | Normal gap value. |
| `ChipsHeight` | `26f` | Default chip height. |
| `ChipHorizontalPadding` | `6f` | Chip inner horizontal padding. |
| `ChipIconSize` | `18f` | Chip icon size. |
