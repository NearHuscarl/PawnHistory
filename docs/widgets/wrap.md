# Wrap

Horizontal flow layout with line wrapping.

| Member | Default | Does |
| --- | --- | --- |
| `children` | none | Children laid out left to right with wrapping. |
| `gap` | `ctx.Theme.GapXs` | Horizontal gap when omitted. |
| `lineGap` | `ctx.Theme.GapXs` | Vertical gap between lines when omitted. |
| `key` | `null` | Explicit identity for this node. |
